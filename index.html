📤 סנכרון

שלח את כל הרשומות הממתינות ל-Sheets

💾 גיבוי ושיתוף נתונים

כל הנתונים שמורים בדפדפן הזה בלבד. ייצוא שומר קובץ JSON שאפשר לגבות, לשתף עם הצוות, או לפתוח במחשב אחר.

📖 הוראות Apps Script

1. פתח Google Sheets חדש

2. תוספות → Apps Script

3. הדבק את הקוד מקובץ google_apps_script.js

4. פרסם → פרוס כאפליקציית אינטרנט → "כל אחד"

5. העתק URL → הגדרות למעלה
